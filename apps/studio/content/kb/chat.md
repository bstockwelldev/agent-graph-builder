Chat is a model scratchpad (⌘⇧C). When a graph is open, it knows the graph, the selected node or edge, and the run you're inspecting, and it can draw on these help articles to explain how the studio works.

## How do I…
- **Ask about a failure:** select the node or open the run, then ask "why did this fail?".
- **Run an agent:** type `/run @agent your input`.
