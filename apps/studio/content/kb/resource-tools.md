Tools are what Tool and Tool-loop nodes call: built-ins (`lookup_topic`, `web_search`, `calculator`), registry tools you define here, or tools on an [MCP server](kb:mcp-servers). A tool can require approval before it runs.

## How do I…
- Define one under **Resources ▸ Tools** (name, description, JSON parameters), then pick it on a Tool node or drag it from the palette.
